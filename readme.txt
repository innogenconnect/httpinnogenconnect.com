INNOGEN CONNECT + INNOGEN TECH — MERGED WEBSITE
================================================

This is one combined static website, prepared from both supplied website ZIP files.
It preserves the original INNOGEN CONNECT content and adds the INNOGEN TECH brand and product section.

PUBLISHING TO YOUR EXISTING NETLIFY SITE
1. Keep a backup of your current deployment and both original ZIP files.
2. Extract this ZIP on your computer.
3. Open the extracted folder; index.html must be at the root of the folder you deploy.
4. In Netlify, open the EXISTING project for innogenconnect.netlify.app.
5. Go to Deploys and use the manual deploy / drag-and-drop area for that existing project.
6. Deploy the folder containing index.html, assets/, and README.txt.
7. Test the live homepage, mobile navigation, product links, form, and mailto contact.

IMPORTANT
- This is a static site. The enquiry form opens a prefilled email draft; it does not store submissions on a server.
- Product images are illustrative concepts, not confirmation of stock or final product specifications.
- Do not delete the second Netlify project until you have checked the merged site is working and saved a backup.
